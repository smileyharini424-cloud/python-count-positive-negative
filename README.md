# Count Positive and Negative Numbers

## Explanation

This Python program counts how many positive and negative numbers are present in a list.

## Problem Statement

Write a Python program to input a list of numbers and count the number of positive and negative values.

## Features

* Accepts multiple numbers.
* Counts positive numbers.
* Counts negative numbers.
* Displays the results clearly.

## How It Works

1. Read the numbers from the user.
2. Store them in a list.
3. Check each number.
4. Increase the positive counter when the number is greater than zero.
5. Increase the negative counter when the number is less than zero.
6. Display both counts.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `split()`
* `map()`
* `int()`

## Program Flow

Input → Store Numbers → Check Each Number → Count Positive/Negative → Display Result

## Sample Input

```text
10 -5 7 -2 0 8 -9
```

## Sample Output

```text
Positive numbers: 3
Negative numbers: 3
```
